# Отчёт о проверке проекта

Дата проверки: 17.11.2026.  
Среда: Windows, PHP 8.5.12 CLI, MariaDB 11.4.5, встроенный сервер PHP (`php -S`).

## 1. Синтаксис

Команда:

```bash
php -l <каждый файл>
```

Результат: **все PHP-файлы синтаксически корректны** (18 файлов, включая шаблоны).

## 2. Модульные проверки логики

Проверялись чистые функции без БД:

- валидная заявка проходит без ошибок;
- латиница в имени, цифры в фамилии, телефон без формата, неверный e-mail отклоняются;
- вчерашняя дата, одинаковые даты заезда/выезда, `32.01.2027` отклоняются;
- `29.02.2028` принимается, `29.02.2027` — нет;
- календарь декабря 2026 начинается со вторника (смещение 1);
- бронь `10.12–13.12` блокирует 10, 11, 12 и не блокирует 13;
- месяц из прошлого ограничивается текущим;
- форматирование площади и цены.

Результат: **все проверки пройдены**.

## 4. Что не проверялось автоматически

- Визуальная проверка в конкретном браузере экзаменационной машины (вёрстка адаптивная, но шрифты/размеры могут отличаться).
- Работа под Apache/XAMPP: проверялся встроенный сервер PHP. Конфигурация Apache не требуется, кроме `public/` как каталога сайта.
- Одновременная конкурентная отправка двух заявок (логика защищена транзакцией `FOR UPDATE`, но нагрузочный тест не проводился).

## 5. Как повторить

1. Импортировать `db/schema.sql` и `db/seed.sql`.
2. Запустить `php -S localhost:8000 -t public` или открыть `public/` через Apache.
3. Пройти чек-лист из `README.md`, раздел 11.
4. Для проверки CSRF отправить POST без скрытого поля `csrf` — ожидается страница 419.
5. Для проверки пересечения выбрать номер 1 и даты одобренной брони из `seed.sql` (сегодня +10 … +13 дней).
