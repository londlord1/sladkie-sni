# Прототипы страниц (Задание 2)

Статические прототипы основных экранов сервиса «Сладкие сны»:

- `index.html` — главная страница;
- `catalog.html` — каталог с фильтром по категории, цене и количеству гостей;
- `booking.html` — форма бронирования с проверкой полей и сообщением об успехе.

## Как открыть

Двойным щелчком по `index.html` или через локальный сервер:

```bash
python3 -m http.server 8099
```

Затем откройте <http://127.0.0.1:8099/>.

## Что демонстрируют прототипы

- Шапка с названием и слоганом, подвал с адресом, режимом работы, телефоном и e-mail.
- Шесть карточек номеров с категорией, ценой, изображением и характеристиками.
- Фильтр по категории, цене и количеству гостей; кнопки «Применить» и «Сбросить фильтр».
- Переход «Забронировать» на страницу бронирования выбранного номера.
- Проверка имени, фамилии, телефона, e-mail и дат; сообщение об успешной отправке.
- Кнопка «Заполнить примером» для быстрой демонстрации успешного сценария.

## Важно

Прототипы статические: данные и проверки выполняются в браузере. В рабочем
сервисе те же правила реализованы на сервере — см. `app/validation.php` и
`app/repository.php`. Прототипы не заменяют рабочие страницы и не обращаются к
базе данных.
